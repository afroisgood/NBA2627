# 杰西卡的AI實驗室 戰力表

Yahoo Fantasy Basketball 聯盟「杰西卡的AI實驗室」（16 隊、H2H 9-Cat）的 2026-27 戰力分析網頁。

**網址：** https://afroisgood.github.io/NBA2627/

內建資料是 2026/10/9 的快照（10/9 waiver 後、石與大小小丑的交易後）。想看最新資料，用下面的「更新資料」功能從 Yahoo 抓。

---

## 怎麼用

網頁由上往下分成幾個區塊。第一次打開會出現「PRESS START」開機畫面，點一下或按任意鍵就能跳過。

### 0. 更新資料（從 Yahoo 抓最新名單和數據）

標題下方會顯示目前資料的日期，旁邊有「↻ 更新資料」按鈕。需要用**電腦版** Chrome、Edge 或 Firefox，並且已經登入 Yahoo。

**第一次設定（只要做一次）**

1. 按「↻ 更新資料」，打開說明面板
2. 用滑鼠把「戰力表更新」按鈕**拖到瀏覽器的書籤列**（看不到書籤列請按 `Ctrl`＋`Shift`＋`B`，Mac 是 `⌘`＋`Shift`＋`B`）

**每次更新**

1. 打開 [Yahoo 聯盟頁面](https://basketball.fantasysports.yahoo.com/nba/1031)
2. 點書籤列上的「戰力表更新」
3. 右下角會出現進度視窗，大約 30 秒後顯示「✅ 完成」
4. 按「▶ 打開戰力表」，再按「確定」，就更新好了

會抓：16 隊目前名單、Yahoo 和 ESPN 的預測、上季數據、本季數據、季前排名、持有率，以及季前排名前 400 名裡所有沒被持有的球員（FA）。開季後控制列會多一個「2026-27 本季實際」選項。

**讓網站也更新（所有人都看得到）**

更新後的資料先只存在你這台電腦。想讓所有人打開網站都看到：

1. 「↻ 更新資料」→「下載網站資料檔」，會下載 `latest.js`
2. 打開 [GitHub 上傳頁面](https://github.com/afroisgood/NBA2627/upload/main/data)（要登入 GitHub），把 `latest.js` 拖進去，按最下面的綠色「Commit changes」
3. 大約 1–10 分鐘後，所有人打開網站都會看到新資料，標題下方會寫「網站共用」

也可以把 `latest.js` 交給 Claude，請它放進 `data` 資料夾。

**要知道的事**

- 更新後的預測只用 Yahoo＋ESPN 兩家平均（FantasyPros 沒辦法從 Yahoo 頁面抓）
- 想刪掉這台電腦的更新資料：「↻ 更新資料」→「清除這台電腦的資料」（網站共用資料不受影響）
- 書籤不能用時，可以改用面板裡的「方法二：貼程式碼」
- ▲▼ 會變成跟「這次更新前」的名次相比

### 1. 我的隊伍摘要

標題下方三張卡，一眼看到你的隊伍「石」：

- **9 項綜合名次**和**不算助攻名次**，旁邊的 ▲▼ 是跟上次更新比的變化
- **強項**（名次最前的 3 項）和**弱項**（名次最後的 2 項）；放棄助攻模式下不把 AST 算進弱項

### 1-1. 上方控制列（DATA／MODE）

控制列會一直固定在畫面上方，切換後整頁的數字都會跟著重算。

| 選項 | 說明 |
|---|---|
| **DATA：2026-27 三家預測** | 用 Yahoo、ESPN、FantasyPros 三家預測的平均場均（預設） |
| **DATA：2025-26 上季實際** | 用上季的實際場均。新秀和上季沒出賽的球員沒有數據，顯示「—」，也不計入球隊加總 |
| **DATA：2026-27 本季實際** | 用本季目前的實際場均。只有從 Yahoo 更新過、而且已經開季才會出現 |
| **DATA：預測＋本季** | 預測和本季實際混在一起：本季打越多場，實際數據佔越重（打 10 場佔 1/3、40 場佔 2/3）。開季後最推薦用這個 |
| **INJ：扣除傷兵** | 缺陣（O）的球員不算、出賽存疑（Q）的打 75 折（預設） |
| **INJ：全部照算** | 傷兵也全額計算 |
| **GP：考慮出賽率** | 每位球員再乘上「預測出賽場數 ÷ 82」。常受傷、常輪休的球員（例如一季只打 50 場）只算約 6 成，比較接近整季真正拿得到的數據（預設） |
| **GP：每場都上** | 當成每位球員每場都健康上場，只看每場平均 |
| **MODE：9 項全算** | 9 項都算進綜合名次（預設） |
| **MODE：放棄助攻** | 綜合名次不算助攻（AST），適合 Punt AST 打法 |

你的選擇會記在瀏覽器裡，下次打開還是同樣的設定。

> 為什麼要考慮出賽率？戰力表原本只看「每場」數據，一位場均很高、但一季只打 50 場的球員，會被當成每週都在。打開「考慮出賽率」後，這類球員會打折，排名比較不會高估「明星多、但常受傷」的隊伍。剛切換時名次旁的 ▲▼ 會反映算法的差異，下次從 Yahoo 更新資料後就會恢復正常。

### 2. VS MODE 對戰預測

1. 在「對手」選單選一隊
2. 畫面會用 9 條雙向血條比較你和對手的每項數據，♛ 標出贏的一方
3. 中間的數字是預測比分（例如 `5 : 4`），下面寫 WIN／LOSE／DRAW

比較方式：雙方數據逐項比，FG%、FT% 比命中率，失誤（TO）少的贏。

- **週次**：從 Yahoo 更新過資料後可以選。會依那週每隊的出賽場數，模擬每天排出最好的 10 人先發（PG、SG、G、SF、PF、F、C、C、Util、Util），加總成一週的預測；排不進先發的場次不算。預設是本週，也可以選「每場平均（不看賽程）」
- **贏面**：每項下面的百分比，是把一週數據的正常起伏算進去後，你贏這項的機率
- **勝率**：9 項贏 5 項以上的機率，和預期能贏幾項
- **本週對手**：從 Yahoo 更新過資料後，對手會自動選成 Yahoo 上你本週真正的對手（選單上標「本週對手」）。你自己換別隊也可以，換了就會照你選的
- **本週實際比分**：開打後再更新資料，下面會顯示 Yahoo 上目前的 9 項實際數據和比分
- 週是以週一到週日計算，第 1 週從開幕日開始；Yahoo 的第 1 週可能比較長，請以畫面上的日期為準

### 3. TRADE MACHINE 交易分析器

手動模擬一筆交易：

1. **你送出**：點選自己隊上的球員（最多 3 人）
2. **交易對象**：選對方隊伍
3. **你換回**：點選對方的球員（最多 3 人）
4. **名單空位補 FA**：送出的人比換回的多時，可以選一位 FA 補位。選單依價值由高到低排序，括號裡是價值，在 waiver 上的會標「waiver」。內建資料只有 Matisse Thybulle、Isaiah Joe 兩位；從 Yahoo 更新後，會列出季前排名前 400 名裡所有沒被持有的球員
5. 按「清除」可以重來

下方會顯示：

- **公平度**：用 Yahoo 季前排名＋持有率估算的市場價值比較，從對方角度看
  - 105% 以上：對方帳面賺
  - 95%–105%：公平
  - 95% 以下：對方帳面虧
- **成交機率**：高／中／低，綜合公平度和對方交易後名次的變化
- **雙方各項名次變化**：交易前後，你和對方在 9 項與綜合名次上的升降

每位球員卡片上的「價值」是數據貢獻（會依預測出賽場次打折），「排名」是 Yahoo 季前排名，「%」是 Yahoo 全站持有率。

### 3-1. 其他隊之間交易

交易分析器上方可以切換「我和別隊交易」和「其他隊之間交易」。後者用來分析聯盟裡別人的交易（已經談好的，或你想預測的）：

1. 選**隊伍 A** 和**隊伍 B**
2. 分別點選兩隊要送出的球員（各最多 3 人）
3. 下方會顯示：
   - 誰贏了這筆交易（看兩隊交易後的平均名次變化）
   - 兩隊的綜合名次、平均名次、H2H 勝率變化
   - **對你的影響**：名次是 16 隊互相比較，別隊變強或變弱，你的名次和勝率也會跟著變
   - 數據價值淨增、公平度（從 A 的角度看帳面賺或虧）
   - 交易後兩隊和你的各項名次

收到人比較多的那隊，會自動釋出隊上價值最低的球員。

### 4. AUTO SCOUT 自動找交易

讓網頁幫你掃過其他 15 隊，找出對你有利、對方也可能接受的交易：

1. **要賣的球員**：選你想送出的球員
2. **類型**：1 換 1、2 換 1（空出的位置補上方「名單空位補 FA」選的球員，沒選就補價值最高的 FA），或兩種都找
3. 按「▶ 搜尋」，約 3 秒會列出最多 8 個方案
4. 喜歡哪個方案，按「套用」就會帶進上面的交易分析器看細節

搜尋條件：公平度在 95%–160% 之間、對方綜合名次不會掉超過 1 名、你的平均名次確實進步。結果依你的名次提升排序。

### 5. FA MACHINE FA 分析器

模擬撿一位 FA 之後，你的名次會怎麼變：

1. **撿進來的 FA**：依價值由高到低排序，括號裡是價值；在 waiver 上的標「waiver」，出賽存疑、缺陣標 Q、O
2. **丟掉的球員**：預設是你隊上價值最低的人
   - 正式名單上限是 13 人（不含 IL）。名單有空位時，可以選「不丟人，直接撿」
   - 名單滿了，這個選項不能選，一定要丟一個人
3. 下方會顯示：
   - 結論：建議撿／差不多／不建議，以及哪幾項進步、哪幾項退步
   - 綜合名次和平均名次的變化
   - 球員價值淨增（撿進來的人減掉丟掉的人）
   - 9 項每場數據和名次的變化
   - 上方 VS 選了週次時：本週對 VS 對手的預測比分和勝率（撿人前 → 撿人後），以及雙方球員本週打幾場；FA 選單也會顯示每位 FA 本週幾場

**AUTO PICKUP 自動推薦**：按「▶ 搜尋」，網頁會把每位 FA 跟你隊上每一位可以丟的人都配一次（名單有空位時也試「不丟人」），列出讓你平均名次進步最多的前 10 位 FA。每位 FA 只列最好的丟人選擇，按「套用」會帶到上面看細節。

- 可以勾「排除 waiver」「排除缺陣（O）」，或只看某個位置（PG／SG／SF／PF／C）
- 不會檢查撿完之後還排不排得出完整的先發位置，結果裡會列出雙方的位置，請自己確認
- 內建資料只有 2 位 FA；用「↻ 更新資料」從 Yahoo 抓過之後，才會有完整清單

### 6. LEAGUE STANDINGS 聯盟排名

16 隊的 9 項數據、各項名次和綜合名次。

- **點欄位標題**可以排序，再點一次反過來排
- ♛ 是該項前 3 名，☠ 是後 3 名
- 底色越深代表名次越前面（分成 1–4、5–8、9–12、13–16 四階）
- ▲▼ 是跟上次更新比的名次變化（內建資料是跟 10/9 waiver 後、交易前比；從 Yahoo 更新後是跟更新前比）
- 反白的那一列是你的隊伍「石」
- **H2H 勝率**：跟其他 15 隊各對戰一次、9 項贏 5 項以上的平均機率，下面是平均贏幾項和勝率排名。比「名次平均」更接近 H2H 實際會發生的事。放棄助攻時一樣是 9 項都比，所以勝率不會因模式改變

### 7. SELECT TEAM 各隊球員

在選單選一隊（預設是石），會顯示該隊每位球員的 9 項數據和球隊加總、排名。

- **價值血條**：球員對球隊的貢獻，跟全聯盟被持有的球員比較。實心往右是正貢獻，虛線往左是拖累球隊
- **IL 球員**會用刪除線標示，不計入球隊數據

## 計算方式（簡要）

- **球隊數據**：把非 IL 球員的場均加總；FG%＝總命中 ÷ 總出手，FT% 同理
- **各項名次**：16 隊逐項排 1–16 名，失誤越少名次越前
- **綜合名次**：9 項名次的平均再排序（放棄助攻模式不算 AST）
- **不考慮出賽場次**：例如 2 換 1 會因為少一個人讓累積數據下降

更完整的演算法、資料來源和開發歷程寫在 [DEVLOG.md](DEVLOG.md)。

## 給維護者

```
src/        原始碼（版面、名單數據、市場數據、主程式、交易分析）
build.py    把 src/ 組成網頁
dist/       組好的網頁（含發布到 Claude Artifact 用的版本）
data/       latest.js：網站共用資料（「下載網站資料檔」產生，上傳取代）
tests/      計算的自動測試（npm test）
tools/      yahoo-update.js：網頁「更新資料」用的程式（build 時會嵌進網頁）；fetch-snippets.js：舊的手動抓資料片段
```

改完 `src/` 之後執行：

```
python3 build.py
```

會同時更新 `dist/` 和根目錄的 `league-power.html`（GitHub Pages 顯示的就是這個檔案）。推送到 `main` 後，網站約 1–2 分鐘更新。

測試（不用安裝套件，需要 Node 22 以上）：

```
npm test
```

GitHub 每次推送都會自動跑測試，並檢查網頁檔有沒有重新建置。
