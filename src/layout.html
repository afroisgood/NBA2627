DATA UPDATE資料更新

從 Yahoo 抓聯盟目前的名單、預測、本季數據、排名和持有率，重新計算戰力。要用電腦版 Chrome、Edge 或 Firefox，並且先登入 Yahoo。

方法一：書籤（第一次設定好，以後點一下就更新）
  1. 第一次使用：用滑鼠把這個按鈕拖到瀏覽器的書籤列（看不到書籤列請按 Ctrl＋Shift＋B，Mac 是 ⌘＋Shift＋B）：
    戰力表更新
  2. 打開 Yahoo 聯盟頁面，點書籤列上的「戰力表更新」。
  3. 右下角會出現進度視窗，大約 30 秒後出現「✅ 完成」，按「▶ 打開戰力表」，再按「確定」就更新好了。
方法二：貼程式碼（書籤不能用時）
  2. 在 Yahoo 聯盟頁面按 F12（Mac：⌥＋⌘＋J），切到 Console，貼上後按 Enter。Chrome 第一次貼上會被擋，先輸入 allow pasting 按 Enter，再貼一次。
  3. 跑完按「▶ 打開戰力表」；或按「複製結果」，貼到下面的框框，再按「套用」。

套用後的資料先存在你這台電腦的這個瀏覽器。想讓所有人打開網站都看到新資料，用下面的「讓網站也更新」。

讓網站也更新（所有人都看得到）
  1. 先用上面的方法更新、套用，確認資料沒問題。
  2. （會下載一個 latest.js）
  3. 打開 GitHub 上傳頁面（要登入 GitHub），把 latest.js 拖進去，按最下面的綠色「Commit changes」。如果問要不要取代舊檔案，選取代。
  4. 大約 1–2 分鐘後，所有人打開網站都會看到新資料。標題下方會寫「網站共用」。

分析聯盟裡其他兩隊之間的交易（例如有人談好、或你想預測的交易）：看誰變強、誰帳面賺，以及對你的名次有什麼影響。收到人比較多的那隊，會自動釋出隊上價值最低的球員。

市場價值 = 季前排名分數 × 70% ＋ Yahoo 持有率 × 30%；多人打包時，單一好球員權重較高（避免 2 個普通球員就換到明星）。數據價值會依預測出賽場次打折。名次模擬沿用聯盟表的算法（各項名次平均）。
